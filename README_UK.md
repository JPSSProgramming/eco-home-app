# Керування Опаленням

Простий навчальний додаток Flutter для керування системами опалення будинку. Цей проект демонструє базові концепції Dart та Flutter, включаючи змінні, типи, функції, класи, віджети та управління станом.

## Функціонал

- **Керування котлом**: Вмикання/вимкання котла для кожної кімнати
- **Керування теплою підлогою**: Управління теплою підлогою на кухні та у ванній
- **Моніторинг температури**: Відстеження температури повітря та води
- **Автоматичний режим**: Автоматичне керування котлом на основі порогових значень температури
- **Статистика в реальному часі**: Перегляд загальної статистики опалення будинку

## Структура Проекту

```
lib/
├── main.dart              # Точка входу в додаток та головний екран
├── models/
│   └── room.dart          # Модель даних кімнати
├── widgets/
│   ├── room_card.dart     # Віджет картки окремої кімнати
│   ├── overview_card.dart # Віджет огляду будинку
│   ├── statistics_card.dart # Віджет відображення статистики
│   ├── device_row.dart    # Віджет рядка керування пристроєм
│   ├── stat_row.dart      # Віджет рядка статистики
│   └── status_colors.dart # Утиліта кольорів статусу
└── screens/              # Підготовлено для майбутніх екранів
```

## Початок Роботи

### Вимоги

- Flutter SDK (3.0 або вище)
- Dart SDK
- Android Studio / VS Code з розширенням Flutter

### Встановлення

1. Клонуйте репозиторій
2. Перейдіть в директорію проекту
3. Встановіть залежності:
   ```bash
   flutter pub get
   ```
4. Запустіть додаток:
   ```bash
   flutter run
   ```

## Використання

- **Перемикання котла**: Використовуйте перемикач для вмикання/вимкання котла для кожної кімнати
- **Перемикання теплої підлоги**: Керуйте теплою підлогою незалежно
- **Автоматичний котел**: Натисніть "Auto Boiler" для автоматичного керування котлами на основі температури (поріг: 21°C)
- **Перегляд статистики**: Перевірте нижню картку для загальної статистики будинку
